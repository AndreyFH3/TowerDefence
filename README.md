# 🏰 Tower Defence (Prototype)

Прототип игрового проекта, демонстрирующий применение Zenject (DI) и UniTask (асинхронность) в архитектуре Unity-приложения.
Реализован с упором на модульность, слабую связанность и масштабируемость кода на базе архитектуры MVP.

---

## ⚙️ Технологии и архитектура

- **Zenject** — внедрение зависимостей и фабричная система для генерации врагов и башен.
- **UniTask** — асинхронная логика волн и поведения врагов без Coroutines.
- **MVP** — разделение логики, слабая связанность между слоями.
- **ScriptableObjects** — конфигурация характеристик, баланса и контента.
- **C# / Unity 6**
- Проект построен с прицелом на чистую архитектуру и возможность расширения (новые типы башен, эффектов и врагов).

> Проект ориентирован на чистую архитектуру.

---

## 🎮 Реализованный функционал

- Система управления волнами с динамическим спауном врагов
- Постройка, улучшение и продажа башен с использованием фабрик Zenject
- Главная башня (ядро) с ограниченным здоровьем и обработкой урона через события
- Базовая экономическая модель (доход, стоимость апгрейдов)
- Минималистичная визуальная часть, ориентированная на демонстрацию логики и UX
---

## 🧩 Практический опыт

- Проектирования DI-контейнеров и фабрик в Zenject 
- Построения асинхронной игровой логики с UniTask без Coroutines  
- Разделения ответственности между Model / Presenter / View 
- Проектирования архитектуры, адаптируемой под добавление нового контента

---

## 🧱 Что можно улучшить

- Улучшение UX и визуала без изменения архитектуры

## 🧠 Подход

Основной фокус — архитектура и управляемость кода. Проект создавался как база для будущих игровых прототипов, где важно быстро масштабировать логику без потери читаемости.
Приоритет: слабая связанность, понятные зависимости, удобство сопровождения.
